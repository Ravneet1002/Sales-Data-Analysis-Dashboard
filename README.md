# 📊 Sales Data Analysis & Interactive Dashboard

An interactive business intelligence dashboard built using Python, Pandas, SQL, Plotly, and Streamlit to analyze retail sales data and discover meaningful business insights.

## 🎯 Project Overview

This project analyzes the Superstore retail dataset to understand sales performance, profitability, product trends, and regional business performance.

The dashboard allows users to interact with the data using filters and explore important business metrics through visualizations and SQL-based analysis.

## 🚀 Features

* **Sales Analysis:** Analyze overall sales and profit performance.
* **Interactive Dashboard:** Explore data using Streamlit.
* **KPI Metrics:** View total sales, total profit, total orders, customers, average order value, and profit margin.
* **Category Analysis:** Compare sales across product categories.
* **Regional Analysis:** Identify profitable regions.
* **Monthly Trends:** Understand changes in sales over time.
* **Product Analysis:** Explore sales and profit by sub-category.
* **Business Insights:** Identify top-performing and low-performing categories, regions, and products.
* **SQL Analysis:** Perform business queries using SQLite.
* **CSV Export:** Download filtered sales data.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Ravneet1002/Sales-Data-Analysis-Dashboard.git
```

### 2. Navigate to the project directory

```bash
cd Sales-Data-Analysis-Dashboard
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the dashboard

```bash
streamlit run app.py
```

The dashboard will open in your web browser.

## 📊 Key Business Insights

The analysis of the Superstore dataset revealed:

* Technology generated the highest category sales.
* The West region recorded the highest regional profit.
* November had the highest monthly sales.
* Tables recorded the lowest profit among sub-categories.
* Technology and Office Supplies had stronger profit margins than Furniture.
